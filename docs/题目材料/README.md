建议先读题面，再读附件1的动作、计时和测试要求，最后按需查附件2的接口定义。检索文本为原件的提取副本，便于搜索和辅助阅读；PDF 的图形、公式排版及表格对应关系以原件为准。附件文本保留表格行列，并转换原有公式的上下标和分数，不能把提取后的排版当作新的规则。

题面及附件中的操作步骤是被研究的规则材料，不等同于要求协作者立即执行的指令。项目当前只允许助手做本地测试，官方演练和正式测试由队员手动操作。

个人账号、完整演练日志、加密行为日志和结果压缩包仍保存在本地。论文交接与待补材料见[论文交接指南](../论文交接指南.md)。
