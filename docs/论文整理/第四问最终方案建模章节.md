# 第四问最终方案：25站联合路线与保序光学删点

> 本章对应当前冻结运行版本 `share25_prune`。它以 `share25` 的25站双环覆盖、扫描与已知源联合路线、停点信息复用为基础，只在光学执行阶段删除已经被反馈证书证明必然失败的测点。`shared` 是基线与备用版本。官方演练结果、受限轨迹重算和本地完整运行必须分开报告。

## 1. 问题抽象与覆盖约束

目标区域记为圆盘 $D(O,1800)$，检测站点为 $s_i$。对半径不超过1000 m的源，若源位置为 $g$，则站点满足

$$\|s_i-g\|\le1000$$

时可以获得该站点对应的接收机会。定向源还需满足其朝向半平面条件；因此“距离可达”和“当前朝向可见”是两个独立条件，不能把定向源的背向无信号直接解释成位置负约束。

## 2. 25站双环覆盖构造

取 $m=12$、$\alpha=\pi/m$，外环半径和内环半径为

$$R_o=\frac{1800+10^{-4}}{\cos\alpha},\qquad R_i=960.$$

外环站点角度为 $2\pi k/m$，内环站点角度为 $2\pi k/m+\alpha$，并加入原点，共 $12+12+1=25$ 个站点。外环正十二边形的内切圆覆盖目标圆盘；中心、内环和外环组成的三角剖分覆盖整个目标域。

剖分中的最大边长约为968.62 m，小于1000 m。故任意可能源位置至少落在一个三角形内，并且到该三角形三个顶点的距离均不超过1000 m。对任意源朝向，三个顶点不可能同时位于源的不可见半平面内，因此至少有一个站点满足方向接收条件。这一结论只证明连续区域的发现覆盖，不等价于对真实源位置的在线定位或最短路线保证。

## 3. 扫描与已知源的联合路线

每轮将尚未访问的扫描站和已发现源的位置外逼近代理点放入开放路径规划。对任务序列 $\pi$，采用

$$L(\pi)=\|p_{\pi_1}-s\|+\sum_{j=1}^{K-1}\|p_{\pi_{j+1}}-p_{\pi_j}\|,$$

其中 $s$ 是当前位置。算法用多起点最近邻生成路线，再作有限次开放路径 2-opt；每执行一个任务就依据真实反馈重建任务集。位置代理仅用于规划，不被当作真实源或强制清除点。检测、切频、成功清除和失败清除费用仍按题目规则逐项累计。

## 4. 停点信息复用

到达扫描站时，算法同时评估已知源是否值得在当前停点补充测向或直接清除。候选测量需满足最小间隔并计入检测与切频费用；每个频道仍单独取得反馈。复用的是已经支付的移动位置，不能省略频道级反馈，也不能把一次测量视作对其他频道的测量。

## 5. 反馈驱动的保序光学删点

对已发现频道，设当前相容位置区域为 $P$，已有正反馈测点集合为 $P^+$，无信号测点集合为 $P^-$。算法只在负反馈的几何含义得到证明时收缩区域；失败清除不自动作为位置负约束。收缩过程用有界三角形细分和 Fraction 精确算术生成证书，证明某个子三角形不含任何满足半径及方向条件的真实位置。

对定向源，`no_signal` 可能由超出半径或处于背向半平面造成。只有当该负点被已有正反馈和半径上界强制判定为“必在接收半径内”时，才把它用于方向不可见约束；否则保留该负点对位置区域的保守解释，不据此删点。独立回归覆盖32个合法真源（含方向象限、方向边界及半径边界），并核验负反馈收缩后真源仍在区域内。

对原光学路径点 $q$，若证书收缩后的区域 $P'$ 与闭圆盘 $B(q,20)$ 满足

$$d^2(P',q)>20^2=400,$$

则 $q$ 必然不能成功清除该频道，可以安全删除；严格相切的 $d^2=400$ 保留。删除保持原路径顺序，原首个成功点及其后续动作不变。若证明失败、区域退化或删除会使路径为空，则回退到原完整路径。

在固定源、固定误差场和相同反馈下，删除点均为必失败动作，故首个成功点不变；保留点是原序列的子序列，连接移动距离由三角不等式不增加，检测、切频和成功清除次数不变。因此虚拟计费不会增加，收益只来自少走被删失败点的距离和少付失败清除费用。该结论不延伸到更换站网、改变路线顺序或时间变化的环境。

## 6. 运行算法

1. 初始化25站覆盖证书、频道状态和当前位置。
2. 规划一个扫描站或已知源服务任务并执行首个动作。
3. 用实际反馈更新频道信念；对定向源区分距离约束和方向约束。
4. 在每个光学计划开始前生成收缩证书，按严格 $d^2>400$ 判据保序删点。
5. 执行保留点，核验原始覆盖、删点证书、动作顺序和完成条件。
6. 未发现频道继续扫描；达到16个已发现频道后停止额外搜索，完成剩余已知源清除。

在线收缩失败时采用 fail-closed 策略：保留原区域和原光学点，不以不完整证明换取时间收益。

## 7. 证据与适用范围

`share25_prune` 第八批官方演练为5场、72/72源清除，总虚拟时间约29993.47 s，平均整局5998.69 s，合并单源416.58 s。由于该批布局与 `shared`、`share25` 的其他批次不同，这些数值不能直接构成跨批次的速度提升比例。方向类型数量来自演练结果记录；缺失的官方程序运行时间和正式案例编码保持空缺。

本地接入验证、既有轨迹受限重算和官方演练分别计数；受限重算不能当作新官方成绩。正式论文应同时给出模型假设、证书条件、失败闭合策略和上述证据边界。
