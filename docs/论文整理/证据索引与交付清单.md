## 2. 指标使用约定

- `total_s`：按题目动作规则累计的虚拟总时间，含移动、检测、实际切频、成功与失败清除。
- 单局单源时间：该局 `total_s / cleared`，必须同时说明成功清除数与完成状态。
- 逐局单源时间平均：先在每局相除，再对各局等权平均。
- 合并单源时间：各局总时间之和除以成功清除数之和。
- `runtime_s`：本地程序的现实计算时间；不等同于官方口径的程序运行时间。
- 统计下降百分比：同批配对数据的“基准均值减候选均值”除以基准均值，不是逐局百分比的平均。

第三问本地234.69秒/源与官方演练239.29秒/源均为合并口径；官方逐局单源时间平均是246.30秒/源。单源原型的234.79秒则属于另一项完整任务实验。论文不能只写“平均230秒”而不说明数据集和分母。

## 3. 主版本如何核对

在项目根目录执行：

```powershell
python -X utf8 tools/run_study.py q3_main --script verify_main_solution.py --
```

校验器只使用Python标准库读取文件，检查15个源码、依赖声明和启动文件的SHA-256以及主函数默认配置，不导入求解器或官方客户端。指纹来源是此前保存的开发冻结和接口发布记录；原记录不被改写。

校验通过表示这些文件仍与证据所对应的版本相同，不代表软件在任何机器或场景下都已重新测试。环境依赖的实际安装版本、官方端行为、文档和补充候选不由这些指纹覆盖。若出现差异，先查看修改内容，不能通过直接覆盖指纹把未验证版本称为原主版。
