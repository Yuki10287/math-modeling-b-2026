# 目录调整说明

本次调整按用途分组。模型算法和参数没有改变，原始实验JSON、图表和冻结指纹文件按原字节保留；对需要读取历史版本的两个辅助脚本，只修正了路径。

| 原路径 | 新路径 |
|---|---|
| 第一、二问代码目录 | `src/q1_q2_geometry` |
| 第三问当前代码目录 | `src/q3_model_v2` |
| 第四问当前代码目录 | `src/q4_model` |
| 第三问最初原型目录 | `archive/q3_prototype` |
| 第三问上一版目录 | `archive/q3_improved` |
| 原根目录的论文整理、总体方案与文献复盘 | `docs` |
| 原题附件、早期演练、早期Word分析、旧压缩包 | `local_data`，仅保存在本地 |

题目PDF因整理时被其他程序占用，仍保留在项目根目录。`tmp` 是本地工作缓存，不是日常阅读入口，不进入Git。

根目录新增两个运行入口，分别转到第三、四问已验证的启动脚本。它们仍由使用者手动选择并开启官方模拟器测试；整理与验证期间不会运行官方模拟器。

## 历史记录的路径口径

历史实验JSON中的路径是实验发生时的来源信息，不通过批量替换改变其原始内容。查找旧记录时：第三、四问及第一、二问原路径在前面加 `src/`，两个早期版本加 `archive/`；旧机器绝对路径只用于溯源。

第四问源码指纹中的 `q4_model/...` 和 `q3_model_v2/...` 以两个代码目录共同的父目录为基准；该父目录现在是 `src`，因此相对键与哈希都不需要修改。第三问指纹以自身代码目录为基准，也无需修改。

内部实验脚本暂不拆成新的Python包：它们包含同目录导入、已冻结源码清单以及历史对照依赖。需要阅读时使用各问的[代码导读](../src/README.md)，即可区分主方案与候选实验。后续若做模块拆分，应作为一次独立重构，用动作序列对照重新确认行为一致。
