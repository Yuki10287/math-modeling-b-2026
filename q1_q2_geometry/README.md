# B题：第一问几何核与第二测点初步实验

本阶段用于把几何模型变成可计算的对象。没有运行官方模拟器，也没有确定第三、四问的最终策略。

## 第一问模型

检测位置 s_i、示向度 θ_i 对应半角 1° 的有向楔形 W_i。令 u_i^- 和 u_i^+ 分别是 θ_i−1°、θ_i+1° 的单位向量，则

W_i = {g: cross(u_i^-,g−s_i)≥0, cross(u_i^+,g−s_i)≤0}。

纯测向定位区域为 P = ∩ W_i。所有边界均为直线，因此有界非空的交集是凸多边形，也可能退化成线段或点。

算法先用线性规划识别空集和无界集，再枚举所有边界直线的交点，只保留满足全部不等式的点，并求凸包。最后枚举凸包顶点对，取最远距离。只有非空有界时返回有限直径。不能把一个任意大框截断后的直径当作原区域的直径。

最小包围圆则枚举两点的直径圆、三点的外接圆以及单点退化圆，检验其覆盖全部顶点。本实现面向少量顶点，最坏 O(n^4)，用于透明验证；顶点多时应更换高效实现。

若顶点集为 V，直径 D=max_{u,v∈V}||u−v||，最小包围圆半径 r*=min_z max_{v∈V}||z−v||。

三角不等式给出 r*≥D/2。边长38米的等边三角形直径为38米，最小包围圆半径为38/√3≈21.93931米，故任何直径38米的圆都不能覆盖它。这也反驳了“D≤40米就能保证一次清除”。该三角形确实可以由题设半角1°的测向楔形构成，geometry.py 的 checks() 给出三个实际测点并验证。

存在可保证一次清除的位置，当且仅当真实可行区域的最小包围圆半径≤20米。若使用的是保守外包区域，其半径≤20仍是充分条件；半径大于20则可能仅是外包偏保守。

进一步定义 K(P)=∩_{g∈P}B(g,20)。从当前位置 s 去最近的 K(P) 内点，可比直接走到最小包围圆圆心节省路程。本阶段总耗时示例统一走到圆心，未优化 K(P) 中的访问点。

## 第二问实验口径

- 单个全向源，第一检测点为原点，第一读数0°，第一真实误差0°。
- 比较7个预先给定的第二测点；源真实距离分别为600、1000、1400米。
- 所有示例真实接收半径设为1500米，所有列出的第二测点在这些案例中均可接收。
- 第二次读数由真实角加指定误差，再保留两位小数。误差条件取−0.99°、0°、+0.99°，避免量化将±1°端点推到界外。
- 各条件是确定性反事实案例，不代表官方误差分布，也不把相同地点的重复检测当作独立样本。算法始终使用题目规定的±1°不确定范围。
- 真实位置仅用于产生观测和解释结果，区域计算不读取真实坐标。
- 初始区域使用首测楔形与半径1500米圆盘的交集。源还须在原点1800米内，本例中这个约束被1500米圆盘包含。
- 第二次更新再加入第二楔形和该点半径1500米圆盘。两个正观测与某个共同R∈[1000,1500]相容，正好要求两次距离均≤1500米。
- 用720边外接正多边形近似圆盘；单个圆盘边界最大外扩约0.014279米。此数不是交集误差或定位半径误差的统一上界，近退化几何可能放大截取差异。
- 暂时忽略 direction 意味着距离大于5米的排除区，保留保守外包区域。空洞处理留待完整状态更新。
- sufficient_receive 表示“到整个初始外包区域最远距离≤1000米”这一充分条件是否成立。false 只表示未通过这个保守检查，不等于一定收不到信号，也不是所有可保证接收位置的完整判定。
- extra_time_s：首测之后，走到第二点加第二次测向的时间。
- total_via_center_s：只有r*≤20时，计算从原点首测开始，经第二点测量，再走到包围圆圆心清除的总时间。包含两次测量共10秒、成功清除5秒及全部移动时间；无切频。
- r*>20的案例不填写完整清除时间，因为本阶段还没有给它们配置后续策略。不得将这些缺失值视为失败清除，也不得用于宣称完整策略性能优劣。

主例源为(1000,0)，第二次额外误差设为0（仍有读数两位小数量化）。选择(1000,100)、(1000,300)、(1000,800)时，两条中心测向线均正交，但包围圆半径分别约17.55、18.23、22.36米。前两种经圆心完成清除的总时间约236.00、283.82秒；第三种尚无一次清除保证。

敏感性案例显示：选(1000,100)时，源距离600、1000、1400米、第二次额外误差为0对应的半径约72.29、17.55、108.42米。单个真值案例中的好点不能直接作为未知距离下的通用策略。

## 从实验到策略

候选点应至少同时考虑：能否可靠接收、观测后区域最坏能缩小多少、走过去的时间，以及后续接近/测量/清除所需时间。

可先比较两种明确而不同的基线：

1. 给定移动预算，在可保证接收的候选区域内，最小化第二次观测后包围圆半径的最坏值。
2. 使用同一候选集，通过一个固定后续策略的短期展开，估算“直至清除”的总时间，并选择估计耗时最小的点。

最坏情形须遍历与首测相容的目标位置和允许的误差，不能只用真实位置或仅用区域中心挑点。网格只提供离散近似；全局保证需要连续区域界或几何证明。

## 复现

Python 3，依赖 numpy、scipy。运行 `python geometry.py`，会执行几何检查、计算7个主例及63个敏感性案例，并生成 results.json。
