# 第三问代码导读

**当前主方案是 `solver.py` 的 time/lean。** 日常运行使用项目根目录的[运行第三问](../../../../运行第三问.cmd)。同目录的其他方案用于实验比较，不因文件名更新就自动取代主方案。

## 先读这条主线

| 顺序 | 文件 | 主要看什么 |
|---|---|---|
| 1 | [solver.py](../code/solver.py) | 一局如何发现、定位、清除与停止 |
| 2 | [belief_model.py](../code/belief_model.py) | 实际反馈怎样更新已知源、定位区域和覆盖状态 |
| 3 | [geometry.py](../../geometry.py) | 方位扇区、区域裁切与可靠清除位置 |
| 4 | [coverage_model.py](../code/coverage_model.py)、[scan_planning.py](../code/scan_planning.py) | 无信号证据、区域覆盖及扫描点选择 |
| 5 | [local_policy.py](../code/local_policy.py)、[recovery.py](../code/recovery.py) | 局部动作费用与定位恢复 |
| 6 | [official_client.py](../../official_client.py) | 请求、反馈、重试、日志及完成核验 |

[v1_solver.py](../code/v1_solver.py)和[baseline_solver.py](../code/baseline_solver.py)虽然名字代表历史阶段，仍被当前求解模块导入，不应直接删除。它们与其他主方案文件共同纳入[冻结记录](../results/main_solution_freeze.json)。

## 按用途找其余文件

| 用途 | 文件或命名 |
|---|---|
| 本地主实验与公开反馈环境 | `benchmark.py`、`environment.py`、`validate_model.py` |
| 主方案接口和几何检查 | `test_client.py`、`coverage_checks.py`、`audit_holdout_replays.py`、`verify_main_solution.py` |
| 联合调度候选 | `joint_solver.py`、`joint_planning.py`、`flexible_coverage.py`，及对应 `benchmark_joint`、`test_joint_*` |
| 成本预测候选 | `forecast_solver.py`、`forecast_policy.py`、`benchmark_forecast.py`、`test_forecast.py` |
| 全局动作价值候选 | `value_solver.py`、`global_value_policy.py`、`value_validation.py`、`benchmark_value.py`、`test_global_value.py` |
| 统计、审计、诊断与绘图 | `analyze_*`、`audit_*`、`diagnose_*`、`summarize_*`、`plot_*` |
| 早期局部实验 | `local_*`，含历史诊断结果JSON |
| 旧打包工具 | `create_release.py`、`package_official.py`；现在通常通过Git同步 |
| 实验记录与图表 | `results/`、`figures/` |

官方个人日志位于 `official_runs/`，缓存位于 `tmp/`，均不进入Git。候选联合调度版的启动脚本保留用于复现；根目录入口始终指向lean。
