# 第三问命令行入口整理与本地验证

2026-09-12：修复整理目录后直接运行客户端无法导入 `solver` 的问题。当前主方案仍为 `time/lean`，10个运行文件与原冻结版本逐字节一致；没有修改算法、参数、原始实验结果或冻结指纹。

## 原因与目录调整

客户端原来位于第三问顶层，8个求解模块被移入 `00_主方案_lean/code/`，直接执行客户端时无法找到 `solver.py`。只添加这一层搜索路径也不完整：求解模块依赖顶层的 `geometry.py`，而客户端在结束时需要读取同目录的10个源码文件来记录版本指纹。`--help` 会在导入求解器前退出，不能发现这些问题；历史实验工具通过临时组装平铺目录，掩盖了直接入口的缺陷。

现将以下8个模块移回第三问顶层，与 [official_client.py](../../official_client.py) 和 [geometry.py](../../geometry.py) 同层：

```text
src/q3_model_v2/
  official_client.py
  geometry.py
  solver.py
  belief_model.py
  local_policy.py
  coverage_model.py
  scan_planning.py
  recovery.py
  v1_solver.py
  baseline_solver.py
  tests/test_direct_entry.py
  00_主方案_lean/        模型说明、实验脚本、结果、冻结证据
  01_... 至 08_...      各阶段实验材料
```

旧位置不保留重复模块。[路径映射](../../../studies.json)只更新8个物理路径，逻辑名称、所属实验组和原始哈希不变。旧实验工具与根目录CMD入口继续可用。

## 验证结果

新增的[直接入口回归](../../tests/test_direct_entry.py)真正启动独立Python进程执行客户端，不经 `tools/run_study.py`，不提供模型模块的 `PYTHONPATH`。测试只允许连接自己启动的随机本地端口；不连接官方模拟器。机器可读记录见[验证摘要](../results/direct_entry_validation_v1.json)。

| 检查 | 结果 |
|---|---|
| 从仓库根目录用相对路径直接启动 | 完整运行、保存日志与轨迹、记录源码指纹、正常退出 |
| 从另一个工作目录用绝对路径启动 | 同上，不依赖当前工作目录寻找模型 |
| 仅复制10个运行文件到空目录 | 全部可导入，客户端帮助可显示 |
| 测试网络限制的反向检查 | 非测试目标在连接前被阻断；缺少限制钩子时探测程序在地址解析前失败 |
| 原有本地HTTP接口测试 | 12项通过 |
| 根目录启动工具 `-CheckOnly` | 通过，不连接模拟器 |
| 原冻结检查 | 第三问15项、第四问15项、share25共17项及8项证据均通过 |
| 第四问三个客户端 | 禁止联网条件下导入及帮助显示通过；本轮没有重跑第四问完整任务 |

直接入口共4项测试通过，测试耗时19.667秒。两次完整运行复用已有接口测试布局 `seed=1000, field=hash`：均清除11个源、执行136个动作、保存120条定位轨迹，整局虚拟时间3100.5112402323秒。全部动作和轨迹与经过冻结指纹校验的同一算法参考运行一致；完成证书、正常退出及日志中的10个源码指纹均通过核对。独立重算动作费用的最大误差为 `2.842170943040401e-14` 秒，清除成功也独立按20米距离条件核验。

这是同一布局的入口与行为回归，不能算作两组独立性能实验，也不是新的官方演练成绩。现有平均单源时间与主方案选择结论维持原评价口径。

## 如何复现与运行

保留完整仓库并按[运行工具说明](../../../../tools/README.md)安装环境。在仓库根目录执行本地回归：

```powershell
python -X utf8 -m unittest discover -s src/q3_model_v2/tests -v
python -X utf8 tools/run_study.py q3_main --tests
```

直接入口测试在 `tmp/q3-direct-entry-*/` 保存本次日志、轨迹和验证JSON，不覆盖历史结果。这些临时原始文件不提交到Git；仓库保留测试程序和上述去除个人路径的验证摘要。

队员手动启动第三问模拟器、等待接口就绪后，可以在仓库根目录执行：

```powershell
python -X utf8 src/q3_model_v2/official_client.py --robot-id YOUR_TEAM_ID --log NEW_LOG.jsonl
```

替换实际队号，每次使用新的日志文件名；若指定子目录，先创建父目录。命令立即连接接口，详细流程见[官方测试操作说明](官方测试操作说明.md)。本轮助手没有执行官方演练或正式测试。
