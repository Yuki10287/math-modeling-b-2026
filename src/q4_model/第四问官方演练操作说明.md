# 第四问官方演练操作说明

当前入口使用已冻结的 `shared` 方案：25站覆盖、扫描与已知源的联合路线、扫描停点信息复用。已通过30组本地压力条件、14项本地HTTP检查和3项阈值检查。使用者后续提供的[五次官方记录](官方演练五次结果分析.md)共63/63源清除、合并503.51秒/源；准备与离线分析期间没有替使用者连接官方模拟器。

## 1. 先准备环境

保留完整项目目录，尤其是相邻的 `q3_model_v2` 文件夹：第四问复用其中的几何核与HTTP通信模块，采用独立的第四问求解与完成证书。

需要Python 3.11或更新版本，以及NumPy、SciPy。在项目根目录执行：

```powershell
python -m pip install -r src/q4_model/requirements.txt
python -X utf8 src/q4_model/verify_release.py
```

第二条只读取本地文件，不连接模拟器。双击入口也会先检查环境及15个发布文件的指纹。若使用另一台电脑，先确认Python可以用 `python` 命令启动；当前电脑也会自动尝试 `D:\Python\python.exe`。

## 2. 由你启动一次问题4演练

1. 登录官方模拟器，先保持空闲。
2. 双击本目录的[运行第四问.cmd](运行第四问.cmd)。输入与模拟器登录一致的参赛队号；端口未修改时直接按回车。
3. 按窗口提示，在模拟器中选择**问题4演练测试**并启动，等倒计时完全结束、接口就绪。
4. 回到程序窗口按回车，程序开始本局的检测与清除。结束时查看完整清除证书、成功清除数、总虚拟时间和退出状态。
5. 同时保存模拟器的结果，特别是**官方干扰源总数**。把它与程序的成功清除数比较，才能核对实际清除比例。

第四问入口不能识别你在模拟器界面选择的是第三问还是第四问；这个模块由你在界面中选择。请使用本页的第四问入口。

## 3. 保存哪些结果

本次客户端记录自动保存在 `src/q4_model/official_runs`：

- `q4-shared-时间-随机编号.jsonl`：每条请求与反馈、源文件指纹和会话汇总。
- 同名加 `.beliefs.json`：定位区域、选点记录、光学覆盖计划及动作轨迹。
- 模拟器导出的结果表或结果截图：总源数、成功清除数、总时间、单源时间及程序运行时间。

两份客户端日志应一起保留；目录已被Git忽略。客户端测得的本地墙钟时间包含通信，不能直接代填模拟器的官方程序运行时间。若以后做正式测试，还需按题目要求导出官方加密行为日志并记录案例编码。

如果程序报错，先保留窗口与日志并查看模拟器当前状态；不要直接在同一局再次启动程序。已有日志不会被覆盖，连接状态不明时程序会停止发送新动作。

## 4. 只想在本地复核

以下命令不启动或连接官方模拟器：

```powershell
python -X utf8 -m unittest discover -s q4_model -p test_thresholds.py -v
python -X utf8 -m unittest discover -s q4_model -p test_q4_client.py -v
python -X utf8 src/q4_model/stress_check.py --out src/q4_model/results/my-stress-check
```

HTTP检查只使用操作系统分配的临时回环端口，拒绝使用2026端口。压力测试输出目录必须是新名字。这些命令是复核方法，不能据此声称获得了新的官方成绩。

详细证据与适用范围见[压力测试与接口验证](第四问压力测试与接口验证.md)。
