# 第四问代码导读

**本目录是 `joint_solver.py` 的 shared 基线配置。** 最终方案为 `share25_prune`；需要复核基线时直接运行 `q4_official_client.py`。

## 主方案阅读顺序

| 顺序 | 文件 | 作用 |
|---|---|---|
| 1 | [joint_solver.py](../../joint_solver.py) | 扫描、源定位、顺路观测、清除与停止的整局流程 |
| 2 | [polar_cover.py](../../polar_cover.py) | 25站双环和36个三角形 |
| 3 | [directional_cover.py](../../directional_cover.py) | 负测点凸包与适用于任意朝向的无源证书 |
| 4 | [localization.py](../../localization.py) | 正反馈定位区域、混合类型情景、测向决策及光学后备 |
| 5 | [route_planning.py](../../route_planning.py) | 扫描任务与已知源任务的联合路线 |
| 6 | [guarded_policy.py](../../guarded_policy.py) | 共享测点的费用评分；类型保守分支未入选 |
| 7 | [q4_official_client.py](../../q4_official_client.py) | 第四问接口会话和独立完成证书复核 |

[solver.py](../../solver.py)保留原31站整局方案作对照，同时向当前方案提供反馈检查函数；[shared.py](../../shared.py)负责定位相邻第三问目录并读取冻结的几何模块。这些都是保留依赖。

## 本地验证与结果

| 文件或目录 | 用途 |
|---|---|
| `benchmark.py`、`benchmark_joint.py` | 自建布局与旧、新方案配对比较 |
| `stress_check.py` | 正负1°误差端点和针对性压力布局 |
| `validation.py` | 反馈、计时、真源包含性、光学覆盖及三角证书审计 |
| `test_model.py`、`test_joint.py`、`test_thresholds.py` | 模型与边界检查 |
| `test_q4_client.py`、`local_http_fixture.py` | 临时回环端口上的接口检查 |
| `summarize_joint_q4.py`、`summarize_readiness.py` | 整理已有证据与发布记录 |
| `verify_release.py` | 只读校验15个发布文件 |
| `results/joint-holdout/` | 24组配对条件的完整记录 |
| `results/stress-endpoints/` | 30组压力条件的完整记录 |
| `results/http-local/` | 两场完整HTTP闭环的可复核记录 |
| `figures/` | 论文图表 |

开始阅读前可先看[模型与路线说明](第四问覆盖与联合路线改进.md)；要运行时看[操作说明](第四问官方演练操作说明.md)；核查可靠性看[压力与接口验证](第四问压力测试与接口验证.md)。个人演练记录和临时测试文件分别在 `official_runs/` 与 `tmp/`，不进入Git。
