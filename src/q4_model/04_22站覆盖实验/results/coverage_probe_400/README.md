# 面向400秒目标的几何探索归档

这是静态覆盖探索，尚未接入整局求解器，没有新官方成绩，也没有修改生产求解代码。400秒的外部参考口径尚未核实。

## 已证明的结果

[22站证书](certificate-22-990.json)采用外环12站、990米内环9站及原点，共22站。外接十二边形分成108个三角细胞，各细胞均有一组证据站满足：三角形位于这些站点的凸包内，而且证据站到三角形所有顶点的距离都不超过1000米。

这保证每个允许的源位置在任意闭180°发射方向下都能被至少一个测站接收。它证明22站可行，不能证明22站最少，也不代表只测任意22次便可确认某频道不存在；实际停止仍需逐频道的真实无信号反馈。

[独立审计结果](independent-exact-audit-22-990.json)使用精确有理数几何：将站点的双精度坐标按其精确二进制值解释，重建精确中点分割的叶细胞。435组父三角形交集、完整剖分面积、圆域包含、1080项距离平方与990项凸包叉积检查全部通过。最大证据站距离约994.9971米；有些凸包约束恰好取等号，不能未经复核任意截断或扰动坐标。

原JSON保存的叶顶点是精确中点坐标的浮点近似，差异最大约1.71e-13米。严格结论针对审计重建的剖分。原生成器的 `hull_apothem` 字段误取了最大边距，真正最小边距由独立审计逐边检验为1800.0001米，以审计结果为准。

可在项目根目录重新核查，不运行任何求解器或模拟器：

```powershell
python -X utf8 tools/run_study.py q4_cells --script independent_exact_audit.py -- --out tmp/coverage-audit-repeat.json
```

## 尚未获得的结果

[静态路线诊断](route-22-diagnostic.json)从实际原点（候选站点数组索引21）出发，找到17891.88米的路线。相比原25站的最短扫描路线18005.67米，仅少113.78米，约22.76虚拟秒。新候选的最小生成树下界是17352.03米，当前路线尚未达到该下界；这些数字都不是整局时间。

因此，减少3个测站的主要潜力可能来自减少检测、以及与定位路线重新结合，尚不能直接推断20.56%的整局提速。当前25站版仍是有五次官方全清记录的稳定基线。

- [21站、内环975米反例](certificate-21.json)：粗筛通过，密筛发现184处漏洞，并保存源位置、朝向及严格背向投影反例。
- [21站、内环990米证书尝试](certificate-21-990.json)：密筛未找到漏洞，但细分至深度12仍有32个未证明细胞，只能记为未证，不能判为连续覆盖。
