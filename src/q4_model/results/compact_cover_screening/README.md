# 更少外环站点的探索：保留负结果

本目录保存本地几何筛查脚本与结果，未连接官方程序，未用于修改官方入口。

共筛查8,224组规则两环布局：3,835组采用最小外接外环，另4,389组将外环外扩2%至16%。外环站点数7至11，内环站点数6至11，带或不带中心；所有候选不超过22站。每组首先检查5,401个位置，全部未通过必要的方向覆盖条件。因此没有候选进入连续覆盖证明或整局求解器。

[反例记录](research_conclusion.json)中，一个22站候选在388,801个密集位置上仍有715个遗漏。取源位置约(779.860542, -1622.276652)、半径1000米、朝向17.338617度，所有站均检测不到：范围内测站的方向投影最大仍为-25.61米，而范围外最近测站距离1003.51米。这是有数值裕量的合法定向源反例。另一内环半径1025米的候选在原点附近也有小漏区。

这些结果只否定受检的具体布局，不能证明更少测站不可能，也不能证明已通过精确审计的22站布局最优。高密度抽样只能找到反例，不能代替连续区域证明。

脚本依赖相邻[已归档的覆盖研究](../coverage_probe_400/README.md)及`route_planning.py`；可在项目环境运行本目录的`search.py`、`search_outer.py`与`counterexample.py`复查。脚本会重写本目录的相应探索结果，复现时建议复制到新目录后运行。
