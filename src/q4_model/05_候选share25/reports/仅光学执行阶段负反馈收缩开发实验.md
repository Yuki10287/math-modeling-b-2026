# 仅光学执行阶段负反馈收缩：开发弱结果

这一轮保持原 25 站、Belief、测向选择、源代理、任务路线和主动测向额度不变，仅在原服务已经决定进入光学兜底后，调用冻结的负反馈区域证明器，再对缩小的外包区域重新生成原矩形光学网格。收缩结果不写入 Belief.P。它检验的是负反馈信息的使用时机，没有调节参数，也没有连接官方模拟器。

五组固定 smooth 本地布局的结果如下。正的节时表示候选更快。

平均总虚拟时间由 6305.460 秒变成 6359.719 秒，慢 0.861%；一胜、两负、两平。两策略均清除 64/64 个源，全部十局真实计费、反馈、原位置区域与连续光学覆盖核验通过。十次实际收缩的完整有理数证明均通过独立检查，并核对了原区域及正负观测来自当时真实日志。五组在第一次应用收缩前的实际事件逐条相同，未发生证明错误回退，运行前后源码指纹一致。

结果说明：严格缩小可行区域不等于启发式光学路径的实际清除时间必然下降。重新生成网格会改变首点、点间距离和访问次序；较小的覆盖范围仍可能让本来较早成功的点排到后面。该实验不替换正式 CLI，不宣称官方收益，也不追加种子挑选好结果。

后续更受约束的方向是保留原光学点及顺序，只删除能证明整个 20 米清除圆盘与可行区域严格不交的点。这样删除依据来自反馈与几何证明，成功点必须保留；它是另一个实验，不能把预期收益写作本轮结论。
