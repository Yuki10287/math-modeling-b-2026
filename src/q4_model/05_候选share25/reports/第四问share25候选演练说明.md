# 第四问 share25 候选演练说明

使用项目根目录的[运行第四问候选.cmd](../../../../运行第四问候选.cmd)运行原候选，窗口应显示 **share25**。原[运行第四问.cmd](../../../../运行第四问.cmd)仍启动已有两批官方演练记录的 `shared` 版本。

交接更新（2026-09-12）：本share25已取得[第六批4次官方演练](../../03_官方演练与时间诊断/reports/官方演练第六批share25结果分析.md)，51/51全清、平均整局6594.44秒、合并517.21秒/源，尚未证实比shared更快。新增的[share25_prune保序删点候选](25站保序删点候选运行说明.md)使用另一个Python入口，尚无官方实测；本页CMD不会启动它。

候选仍使用25站覆盖，增加测量后的全局任务重排，以及源服务停点的信息复用。在20组新本地配对条件中平均提速6.04%，另30组压力条件全部通过；这些是本地结果，详见[模型改进实验](第四问模型改进实验.md)。本次只新增独立接入入口，求解代码保持留出前的冻结版本。

## 1. 操作顺序

1. 保留完整项目，登录官方模拟器，先保持空闲。
2. 双击根目录的 **运行第四问候选.cmd**。程序先核对Python环境和发布文件，再让你输入参赛队号。队号须与模拟器一致。
3. 输入端口；未修改官方端口时直接回车，默认2026。
4. 按窗口提示，在模拟器中选择 **问题4演练测试** 并启动。等倒计时结束、接口就绪，再回到候选窗口按回车，程序才开始操作。
5. 结束时查看“完整清除证书：通过”“退出请求：已接受”，并将客户端成功清除数与官方源总数核对。保存模拟器结果和两份客户端日志。

入口不能识别模拟器界面选的是第三问还是第四问，需要你在界面选对模块。一次演练只运行一个程序窗口。若报错，先保存窗口信息与日志，查看当前演练状态；不要直接在同一局重新启动候选。

## 2. 日志与测试记录

使用CMD入口时，候选日志自动保存在 `local_data/official_runs/share25/`；使用[直接命令行](../../README.md)时，日志写入 `--log` 指定位置。CMD自动命名如下：

- `share25-时间-随机编号.jsonl`：请求与反馈、`variant=share25`、运行源码指纹及最终汇总。
- 同名加 `.beliefs.json`：定位可行域、选点、光学覆盖及动作轨迹。

两份文件一起保留，旧日志不会覆盖，日志目录已被Git忽略。请另外记录官方源总数、全向/定向数量、成功清除数、总时间或单源时间及官方程序运行时间；有案例编码或官方导出日志时也一起保存。客户端本地耗时包含通信，不能代替官方程序运行时间。

先收集5次有效演练。如果模拟器支持同一案例重复运行，可让旧版与候选做配对；不能重复时，两批不同案例的均值差不能直接解释为优化幅度。

## 3. 环境与只读检查

需要Python 3.11或更新版本、NumPy和SciPy。当前电脑会优先尝试 `D:\Python\python.exe`，随后尝试 `python`。在项目根目录执行：

```powershell
python -m pip install -r src/q4_model/02_主方案25站_shared/code/requirements.txt
python -X utf8 tools/run_study.py q4_share --script verify_share25_release.py --
```

第二条只读取本地发布文件与验证记录，不导入客户端、不连接模拟器。候选入口也会先运行这项核对；校验失败时不会继续连接。在另一台电脑运行时，须保留相邻的 `src/q3_model_v2`，因为第四问复用其中已验证的几何与通信模块。
