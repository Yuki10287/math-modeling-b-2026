# 第三问改进版与本地对照实验

本目录包含原版、增加光学后备处理的版本，以及联合安排扫描和清除顺序的动态调度版本。当前改进和验证仅针对第三问全向源，全部结果来自本地自建环境与本地接口替身。本轮没有连接官方模拟器，没有启动官方演练或正式测试。

先阅读 [方案与实验结果](方案与实验结果.md)。原始压缩包、已有演练日志和表格没有修改；`baseline_solver.py` 与原压缩包中的 `solver.py` 字节一致。

## 三个对照版本

| 参数 | 行为 |
|---|---|
| `baseline` | 原版时间导向单源定位，扫完当前站后清除该批目标 |
| `safe` | 保留原访问顺序，加入数值异常或定位步数耗尽后的光学覆盖搜索 |
| `dynamic` | 保留单源定位与后备方法，将已发现源和未访问扫描点一起安排访问顺序 |

改进版的全清判断使用已接受的公开反馈：16个不同频道清除成功，或20个频道均已清除/在七个覆盖点全部测得无信号。`/exit` 成功本身不是全清证据。

## 本地复现

在本目录运行。核心实验需要 Python 3.11 及以上和 `numpy==2.3.5`；依赖列在 `requirements.txt`。不需要联网服务或付费接口。

```powershell
python recovery_checks.py
python validate.py --policy time
python test_client.py
python benchmark.py --start-seed 2000 --seeds 20 --split holdout --out results/reproduced-holdout
```

最后一条命令会运行20种固定随机布局、3种固定地点误差场和3种调度，共180次本地测试。输出目录必须不存在，避免覆盖旧结果。再次运行时换一个新的目录名。相同代码、NumPy和种子下动作及虚拟时间应可复现，实际计算用时可能不同。

`test_client.py` 只创建临时回环接口替身，不使用官方端口。`official_client.py` 仅作为尚未实际连接验证的适配代码保留，不在上述本地复现流程中自动运行。

绘图可选，需要 Matplotlib。运行 `python plot_results.py` 读取已保存的留出实验结果，更新 `figures/` 中的图。

## 文件与结果

| 文件 | 用途 |
|---|---|
| `solver.py` | 三版本统一入口、动态路线和完成证书 |
| `recovery.py` | 与原版一致的正常单源处理，以及152点光学后备方案 |
| `baseline_solver.py` | 未改动的原版求解代码 |
| `environment.py` | 未改动的本地环境，真值只供模拟器及事后审计使用 |
| `benchmark.py` | 配对场景、逐动作留档、指标汇总与计时复核 |
| `validate.py` | 边界布局、信息隔离、完成证据及异常传播检查 |
| `recovery_checks.py` | 光学覆盖、强制恢复、正常动作一致性检查 |
| `official_client.py` / `test_client.py` | 通信适配代码及仅在本地运行的替身检查 |
| `results/development-v1/` | 10种开发布局 × 3误差场 × 3版本 |
| `results/holdout-v1/` | 冻结策略后20种新布局 × 3误差场 × 3版本 |
| `validation-results.json` | 主压力检查和故障注入结果 |
| `recovery_check_results.json` | 单源光学后备与原版一致性结果 |
| `http-validation.json` | 本地通信替身验证结果 |
| `figures/` | 配对性能图与中位改善案例的路线图 |

每组实验保留运行前代码校验值、环境版本、每次结果、源真值、动作和定位区域。求解函数不接收源真值；只在测试完成后用真值审计。图中的真实源位置也仅用于事后展示。

## 范围和限制

- 动态路线以候选区域中心作代理位置，采用有限搜索，并非全局最优控制。它可能在个别场景变慢。
- 没有实现跨频道共享观测、定向源搜索或第四问策略。
- 光学后备方案保证在有效首测和题设几何条件下有限次覆盖该源；不能单凭此保证所有运行环境下都满足现实20分钟预算。
- 本地误差场、源位置及接收半径分布为自定义测试条件，不能把这里的成功比例直接当作官方模拟器成功率。
- 调试JSONL与结果JSON不替代题目要求的正式加密行为日志。
