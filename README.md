## 本地检查

Python 3.11或更新版本，在项目根目录执行：

```powershell
python -m pip install -r src/q4_model/requirements.txt
python -X utf8 tools/check_structure.py
```

第二条只检查本地文件、入口与冻结版本，不运行官方接口。第三、四问代码目录应保持相邻，不要只单独拷贝第四问文件夹。

## GitHub同步

代码、说明和可复现的本地实验进入Git；个人日志、原题附件、缓存和旧压缩包留在本地。修改后检查差异、提交，再推送；另一台电脑使用 `git pull --ff-only` 获取更新。当前目录结构在Windows上保留冻结文件原始字节，避免换行转换改变校验值。
